# Dairy Management System

A modular Dairy Management System.

## Technology Stack

- React with JavaScript
- ASP.NET Core Web API (.NET 10)
- SQL Server
- Entity Framework Core
- JWT Authentication
- Clean Architecture
- Repository and Unit of Work

## Project Structure

- backend: .NET solution
- frontend: React application
- database: Database scripts
- docs: Technical documentation

## Frontend Setup

cd frontend/dairy-management-ui
npm install
npm run dev

## Backend Setup

Open backend/DairyManagementSystem.sln in Visual Studio.
